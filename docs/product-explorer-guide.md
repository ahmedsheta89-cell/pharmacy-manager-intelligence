# مستكشف الأصناف الكامل

يعرض مستكشف الأصناف جميع الأصناف الناتجة من ملف التحليل المعتمد، وليس أول مائة نتيجة. يمكن البحث باسم الصنف أو كوده أو الشركة، ثم اختيار الرصيد الصفري أو الموجب أو غير المتاح، والفرز بحسب أولوية المراجعة أو كمية الصرف أو الرصيد أو السعر أو التكلفة أو الهامش أو قيمة الرصيد.

| القيمة | متى تظهر | طريقة القراءة أو الحساب |
|---|---|---|
| الرصيد الصفري | عندما تكون قيمة عمود الرصيد المعتمد مساوية للصفر تمامًا | قيمة فعلية من الملف |
| سعر البيع وسعر الشراء | عند اعتماد عمود سعر البيع أو التكلفة، أو عند مطابقة ملف أسعار موثق | قيمة فعلية من المصدر |
| قيمة الرصيد | عند توافر الرصيد وسعر البيع | الرصيد × سعر البيع |
| قيمة التكلفة والربح | عند توافر الرصيد والتكلفة، وعند توافر السعرين معًا | الرصيد × التكلفة، والفارق بين قيمة البيع والتكلفة |
| كمية الصرف والمبيعات | عند توافر عمود الكمية أو المبيعات المعتمد | قيمة فعلية أو مجموع سجلات الصنف |
| الهامش | عند توافر المبيعات والربح أو التكلفة مع المبيعات | الربح ÷ المبيعات × 100 |

> **غير متاح** لا تساوي صفرًا. تعني أن الملف لم يتضمن الحقل أو أن المدير لم يعتمد خريطته بعد. لا تُنشئ الأداة تكلفة أو ربحًا تقديريًا عند غياب المصدر.

تظهر أصناف الرصيد الصفري في بطاقة مستقلة بالعدد، وتعرض قيمتها بسعر البيع والتكلفة فقط عندما يسمح مصدر البيانات بذلك. يظل القرار الشرائي يدويًا، ولا يغيّر أي فلتر ملف Excel المصدر أو أي كمية تشغيلية.

## تصدير النتائج الحالية

يتيح زر **«تصدير نتائج المستكشف الحالية»** تنزيل ملف Excel محلي يحتوي على كل الصفوف المطابقة للفلاتر والفرز الحاليين، بلا سقف مائة صف. يتضمن الملف ورقة للنتائج وورقة أخرى تسجل الفلاتر التي كانت مفعلة عند التصدير. تحتفظ الخلايا بقيمة **«غير متاح»** عندما يغيب سعر الشراء أو الربح أو أي حقل مصدر؛ لا يحول التصدير هذه الحالة إلى صفر.
